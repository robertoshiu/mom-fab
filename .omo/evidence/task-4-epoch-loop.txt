== Hook-order assertion at epoch boundary (4A spec) ==
The scheduler OWNS the order; state/choreography are injected callbacks.
Full observed boundary order:
  freeze -> epochEnd -> snapshot -> clear -> choreo -> resume
4A core data order (excluding the epochEnd boundary signal):
  freeze -> snapshot -> clear -> [RESET currentTick=0 + epochSeed] -> choreo -> resume
  -> PASS  (matches plan 4A: snapshot BEFORE clear, snapshot BEFORE reset)
Note: [RESET] (currentTick=0, epochSeed update) executes in code between the
clear hook and the choreography hook; it is an internal scheduler step, not an
injected callback, so it does not appear as a named hook in the order array.
